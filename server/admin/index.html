使用提示

  • 侧栏顺序与官网顶栏一致。方案 / 产品 / 新闻、全站、系统均用顶部 Tab 切换子功能。
  • 只改中文；正文可用工具栏排版，不用写代码。
  • 改完后用页面底部的保存；可用顶栏「打开官网」或底部「预览」查看效果。
  • 英文 / 俄文：打开「系统 → 翻译同步」，有待同步时点「立即同步」即可。
