# 同兴高科后台视觉与体验设计规范（A+ 方案）

## 1. 目标

后台以“好找、好看、好用、整齐”为目标，保留左侧导航和前后台页面一一对应的内容架构，不改变现有接口、数据结构和业务流程。

- 好找：运营人员可以按照前台页面找到后台修改位置。
- 好看：延续前台黑、白、灰和品牌橙的工业科技感。
- 好用：相同操作始终出现在相同位置，长页面也能快速保存。
- 整齐：页面、卡片、列表、表格和表单遵循统一尺寸与对齐规则。

## 2. 信息架构

```text
工作台

页面管理
  首页
  关于我们
  解决方案
  产品中心
  新闻中心
  联系我们

网站资源
  全站设置
  素材库

系统
  系统管理
```

分类设置归入对应内容中心；全站共用内容归入全站设置；图片归入素材库；多语言同步、术语表、访问概况、操作记录、备份与恢复、账号管理归入系统管理。

## 3. 视觉变量

| 用途 | 规范 |
| --- | --- |
| 品牌主色 | `#FF6B00`（与前台一致；token 见 `server/admin/admin.css` → `--txam-orange`） |
| 主文字 | `#171717` |
| 次要文字 | `#667085` |
| 页面背景 | `#F5F6F8` |
| 卡片背景 | `#FFFFFF` |
| 边框 | `#E4E7EC` |
| 浅橙背景 | `#FFF4EB` |
| 成功 | `#169B62` |
| 警告 | `#E58A00` |
| 错误 | `#D92D20` |

- 主标题：24px / 700。
- 卡片标题：16px / 700。
- 正文与表格：14px。
- 辅助说明：12–13px。
- 数据数字：28–32px / 700。
- 控件圆角：8px；卡片圆角：12px。
- 间距使用 8、12、16、24、32px 五档。

## 4. 全局布局

- 左侧导航固定宽度 248px，Logo 区高度 76px，导航项高度 44px。
- 右侧内容最大宽度 1440px，超宽屏居中显示。
- 大屏左右内边距 32px，普通屏 24px，小屏 16px。
- 页面标题、筛选区、内容卡片、表格和分页使用同一左右基准线。
- 页面本身负责纵向滚动，除素材网格、长任务列表等明确场景外不使用嵌套纵向滚动。

## 5. 页面头部

所有页面统一为“标题与说明在左，预览、刷新、新增等页面级操作在右”。同一操作区最多一个品牌橙主按钮。

内容中心的页面设置、内容管理、分类管理使用统一模式导航；深层编辑使用抽屉，并显示基本信息、正文内容、发布设置等区块导航。

## 6. 列表与表格

- 表头高度 48px；普通行最小高度 60px；带缩略图的内容行 72px。
- 图片、序号、状态居中；标题和名称左对齐；数字右对齐；操作固定在最右侧。
- 缩略图尺寸固定，使用 `object-fit: cover`，不得撑高数据行。
- 标题最多两行，辅助信息单行省略。
- 仅保留横向分隔线，悬停行使用浅暖灰背景。
- 操作区统一为编辑主操作，删除等危险操作放入编辑页或二次确认流程。
- 筛选区、内容区、数量统计和分页形成一张完整的数据工作台。

## 7. 编辑表单

- 编辑抽屉采用主要内容区块加固定保存栏。
- 输入框和下拉框高度 42–44px，多行文本至少 112px。
- 标签位于控件上方，必填、帮助、错误信息位置固定。
- 标题、分类、封面等高频字段优先；SEO、技术参数等放入高级设置。
- 不展示运营人员不需要的链接、打开方式、占列、悬停样式等代码实现字段。
- 保存中、成功、失败和未保存状态必须明确反馈；未保存离开时提示。

## 8. 六类页面模板

1. 工作台：数据概览、待办、快捷入口、最近更新和网站访问。
2. 内容列表：产品、方案、新闻及分类，使用统一筛选和稳定列宽。
3. 内容编辑：统一抽屉、区块导航和固定保存栏。
4. 页面地图：首页、关于我们、联系我们、全站设置，顺序与前台一致。
5. 素材管理：统一图片比例、搜索、上传、说明编辑和删除。
6. 系统任务：多语言同步、术语表、访问概况、操作记录、备份与恢复和账号管理，使用统一的 tx-hero 横幅和标准 data-table。

## 9. 页面专项规则

### 工作台

- 数据卡片区分访问、内容和待办状态，品牌橙只突出待处理信息。
- 快捷入口保持单行等宽，图标和文字统一。
- 最近更新最多展示常用数量，行高一致。
- 访问概况优先展示中文页面名称，不直接把技术路径当作主标题。
- 避免卡片内部出现无意义的纵向滚动条。

### 页面地图

- 左侧区块顺序与前台从上到下一致。
- 当前区块使用橙色状态标记，未保存区块显示小圆点。
- 右侧表单限制阅读宽度，重复内容使用编号卡片。
- 保存栏说明具体影响的前台页面。

### 素材库

- 图片预览固定比例；标题最多两行；说明输入与删除操作位置固定。
- 大屏每行 4–5 张，中屏 3 张，小屏 2 张。
- 不展示物理路径、服务器目录等技术信息。

### 系统管理

- 使用统一的 tx-hero 横幅（kicker + 标题 + 说明 + 统计行）作为各子面板的顶部。
- 多语言同步：自动调度状态、API 使用记录、同步任务历史。
- 术语表：全局翻译记忆管理，保证中文跨条目译法一致。
- 访问概况：按日 PV、趋势图、栏目占比和页面排行。
- 操作记录：登录和写操作的只读审计日志，支持按类型/操作人筛选。
- 备份与恢复：自动备份 + 手动备份 + 历史恢复。
- 账号管理（仅超级管理员可见）：后台账号增删改、角色分配、密码重置。
- 所有表格使用统一的 data-table（colgroup 列宽 + 静态骨架 + JS 渲染 tbody + table-foot 计数）。
- 表格操作按钮统一为紧凑的 btn-table 样式（仅文字宽度）。

## 10. 响应式

- 1440px 以上：完整导航、双栏编辑和 4–5 列素材。
- 1024–1439px：24px 内容边距，压缩次要信息。
- 768–1023px：页面地图改为顶部横向导航，编辑区单栏，表格受控横向滚动。
- 768px 以下：导航转为紧凑模式，操作按钮可换行但保持主次层级。
- 任何常用宽度都不得出现整页横向溢出。

## 11. 交互反馈

- 保存、上传、同步等异步操作显示处理中状态。
- 成功使用轻提示；失败说明原因；删除明确对象名称并二次确认。
- 空数据提供原因和下一步动作；加载使用稳定占位，避免布局跳动。
- 动画控制在 150–200ms，并尊重系统的减少动态效果设置。

## 12. 验收标准

- 所有页面标题、内容边界和操作区位置一致。
- 所有列表行高、缩略图、状态和操作区对齐一致。
- 长标题、空数据、图片失败和窄屏状态均不破坏布局。
- 编辑页保存操作始终容易找到。
- 页面地图与前台顺序一致，运营端不出现无意义代码字段。
- 1920、1440、1366、1024 和 820px 宽度下无整页横向溢出。
- JavaScript 语法、数据校验、重复 ID 和浏览器控制台检查通过。
