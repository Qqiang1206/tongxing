# 三大列表页统一 · 错落式杂志网格（Bento）

## 设计概念

三个列表页（产品/方案/新闻）统一用**同一套卡片语言**（图片顶部、徽章、等宽小行、标题、摘要、查看详情箭头——即新闻卡骨架），但卡片**大小与形态按节奏变化**，形成错落拼贴：

```
┌───────────────────────────┬───────────┬───────────┐
│  宽卡（横版：左图右文）          │  标准卡     │  标准卡     │
│  SOLUTION 01 TV/商显生产线    │  冰箱生产线  │  包装物流    │
│  描述更完整 + 关键指标条        │  简介+标签  │           │
│  查看详情 →                  │  查看详情 → │           │
├───────────┬───────────────┴───────────┼───────────┤
│  标准卡     │  宽卡（竖版：大图 16:9）      │  标准卡     │
│  洗衣机     │  电容器产线（完整简介）        │  空调产线   │
├───────────┼───────────┬───────────────┴───────────┤
│  标准卡     │  标准卡     │  宽卡（横版）…               │
└───────────┴───────────┴───────────────────────────┘
```

- **节奏规则**（按序号循环，纯确定性、无随机）：每 6 张一组 —— 第 1 张横版宽卡（占 2 列）、第 4 张竖版宽卡（占 2 列），其余标准卡；`grid-auto-flow: dense` 自动填缝，筛选后自动重新拼排，永远和谐
- **宽卡**信息更丰富（更长摘要 + 关键指标条），**标准卡**克制——大小不一但语言统一
- 移动端全部单列，自然退化为普通列表

## 实施改动

1. **共享节奏助手**（`site-common.js` 加一个小函数）：按索引返回 span 类与形态标记，三个渲染器共用
2. **`news-list.js`**：保留现有 featured 首条跨列逻辑，其余卡片套用节奏规则
3. **`products-list.js` / `solutions-list.js`**：卡片构建改为新闻卡骨架 + 节奏类（整卡 `<a>`、`news-card` 基类复用全部样式与悬停态）；产品卡徽章=分类/等宽行=型号/规格徽章行；方案卡徽章=关键指标值/等宽行=SOLUTION 序号/✓ 特性标签
4. **CSS（门控）**：宽卡横竖两种形态的内部布局 + 图片宽高比（横版 4:3 图、竖版 16:9 大图）；筛选过渡层已覆盖
5. 三语自动生效（渲染器共享）；CMS 数据零改动
